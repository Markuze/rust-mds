## Provider-local seam decision

- `Source` fixes provider/profile/origin/boot and executable/config/format hashes. Origin is Fixture or Unqualified only. There is no native flag or native-qualified constructor.
- `Row` carries bounded raw emitted payload bytes, an optional transient original header prefix and optional raw wall timestamp, plus `Ref`: whole original source/cursor byte span, clock interval, CPU, PID/start, TID/task-start and optional instance attribution. Future collectors must obtain header identity independently. Prefix bytes never enter persisted output. Consecutive adapter counters are not upstream completeness.
- `Fact` contains only a finite whitelist of sanitized scalars/hashes and the original Ref. Raw debug/auth/data bytes never enter persisted artifacts. Unknown required rows fail rather than becoming guessed facts.
- `PeerObserver.feed(Row or source-bound Probe)` decodes pinned emitted payloads. `join(provider-local Wire records, Identity)` requires exact source identity/stream and unique ordered multi-record joins. Wire/identity records are standalone adapter inputs, not imports of active P1/P2 APIs. Passive Probe fields refer to existing call arguments/returns; their actual installed ABI/access/association remains unqualified.
- `CallTrace` joins one original worker Intent/entry/exit/Return with a separate FD/root/mount argument anchor. Receipt fsync has its own FD. Kernel restart requires an explicit continuation observation; a second userspace call cannot replace the original.
- `ProviderIO` requires injected open/read/snapshot/drain/close/clock and persistence functions. Defaults/imports do no I/O. Source continuity includes original offsets, all relevant CPUs, log rotation/tails, kmsg sequence and packet-producer counters. A final receipt is released only after drain, sanitized persistence/fsync, close and revalidation.
- Clock values are integer same-boot intervals. Wall conversion needs start/intermediate/end brackets, bounded gaps/drift and step observations. Overlap remains unproved. Negative cut observations remain preliminary until complete drained coverage and retrospective revalidation.

## Scope and adapter obligations

- All outputs remain `OFFLINE_VALIDATED`. `Source.origin` is Fixture or Unqualified. No constructor, profile, normalized JSON, boolean or receipt establishes native completeness.
- `MountAnchor` and `StreamAnchor` state explicit independent mount/fsid/client/UNIQ-ID and advertised address/nonce/source-entity edges. Kernel identity does not use the workload PID as the kernel socket owner. Library joins require PID/start, thread/task-start, exact Client instance and owned source/stream.
- `Wire` is a small local processing projection. It is not the P1 API or a complete wire artifact. Full fronts, paths, reclaim address unions, frame/session identity and independent continuity must remain in P1 artifacts. Its address hashes only select the RESET outcome here. P4 must not replace complete P1/P2 records with this projection.
- `join_call` requires an opcode and exact independently anchored raw-name hashes for metadata request→syscall edges. Timing and mount equality alone fail. Fsync/flush-to-worker and NFS callback edges must retain their independent FD/inode/request joins in the later explicit P4 adapter; this package does not declare them from timing alone. `CallTrace` separately validates the exact original fsync and receipt FD.
- Session OPEN transport remains a missing processing prerequisite. Grace reduction proves only observed owned entry/reload/count/exit records. It does not assess NFS reclaim/owner/conflict cases. P2 hooks use source references and explicit future adapters; no duplicate NFS parser exists.
- `ProviderIO` requires bounded synchronous callbacks. `open` receives Limits. `read/drain` receive handle, remaining raw bytes, remaining records and deadline. Callbacks must enforce these limits before allocation and return original producer metadata. `close` stops the producer and releases source descriptors. Later `snapshot` calls return its latched terminal state. Real callback access, blocking behavior, counters and truthfulness remain unqualified.
- The default limits are 4096 source records, 4MiB raw bytes, 4MiB sanitized artifact bytes including source/clock receipts, 4096-byte whole lines/partials, queue128, FD8, 300s and256 drain reads. CPU count≤256. Checkpoint count≤records+4×drain_reads+16. Join work is capped before scanning at wire_count×max(1,source_count)²≤16,777,216. Limits fail; nothing is evicted or truncated.
- `finish` drains, fsyncs facts, drains delayed input, fsyncs facts again, verifies terminal coverage, closes the source, writes sanitized source/clock receipts, fsyncs the artifact, closes it, fsyncs its directory and revalidates the latched source/clock after persistence. Loss, an unread tail, changed source or late clock step prevents a receipt. Failures close injected resources without a receipt. Close is not retried after an uncertain close error.
- `no_reply_before` and `pending_at` are offline predicates. Re-run them against the final inventory/coverage. Delayed pre-cut reply/exit/loss invalidates preliminary evidence. P4 must preserve the independently persisted source artifact and all required case predicates. No native G3 or installed-provider readiness claim follows.
- `Decoder` accepts a narrow, pinned required-payload grammar. Unknown required rows fail. It does not parse native outer headers or qualify a real logger's filtering/flush configuration.
